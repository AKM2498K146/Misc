# 好好码字 · HHMZBOOK 转 TXT 工具

一个纯浏览器本地运行的格式转换工具，把 HHMZ Book Archive 项目文件（`.hhmzbook` / `.hhbak`）里的正文抽出来，存成纯文本。

## 这东西是干嘛的

写小说的人换编辑器、换电脑、想给稿子留个纯文本备份时用。打开网页 → 选文件 → 点转换 → 拿到一个 `.txt`。

**它本质上就是把一个穿了马甲的文本文档扒出来**：`.hhmzbook` 里装的是 gzip 压缩的 JSON，不是加密，也没有技术保护措施。

## 特点

- **完全本地**：文件不上传、不经过任何服务器，解析在浏览器内存里完成
- **三个按钮，各走各的路**
  - `转换为 TXT` —— 浏览器下载，走文件名
  - `分享` —— 调系统分享面板，文件名交给系统处理，中文最稳
  - `另存` —— 调系统另存为对话框，桌面 Chrome/Edge 会弹出真正的另存为窗口
- **可自定义文件名**：转换前能改输出文件的名字
- **单文件**：整个工具就是一个 HTML 文件，双击就能用，不用装任何东西，也不用联网
- **支持多段数据块**：存档分块导出时（如 `1/2` + `2/2`）会自动拼接

## 怎么用

1. 下载 `hhmz_to_txt.html`，双击用浏览器打开
2. 拖一个 `.hhmzbook` 文件进去，或点区域选文件
3. 想改输出文件名就在输入框里改（默认已自动填好作品名）
4. 点「转换为 TXT」<调用下载器>；也可以选择「分享」或「另存」<调用系统另存保存器>

换样式只动 `<style>` 那段，改解析逻辑只动 `parse()`。
